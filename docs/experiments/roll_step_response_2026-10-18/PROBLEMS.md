# 实施问题与口径

1. 内部5 s随机命令重采样会污染脚本计划：每步观测前设置相同确定时间表，
   并覆盖_resample_commands。记录完整actor输入和GRU历史命令槽，不能只相信脚本设定。
2. 边界帧存在因果时序：10 s状态由旧命令推进，新命令影响下一20 ms；
   保存两类命令，阶段按此前物理区间分组，各恰好500帧，不制造瞬时响应。
3. 失接触不一定是有净空的迈步：主表明示contact-defined swing代理，
   另存失接触且净空>1 cm占比。净空使用已校准原圆柱转胶囊碰撞体，不误用圆柱公式。
4. 原终止累积计数与几何跌倒分开；保留失败后的真实轨迹，不把后续复位新episode拼成一个连续响应。
   条件均值同时报告有效环境、时长、完成数量，全分配样本统计另存，不隐去失败。
5. 两段纯滚动有不同历史，四阶段主表分开；三条件补充表在每环境内合并后重新计算，
   不能把两个RMSE直接平均，也不把同一环境前后两段当独立复验。
6. 一个训练seed的既有策略，3评测seed不代表多训练seed；不作控制器间对比或模式切换新研究。
