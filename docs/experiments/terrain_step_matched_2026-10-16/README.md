## 地形的实际物理定义

- 三类均使用真实三角碰撞网格，不改变重力方向，不施加坡面代理外力。
- 平地为零高程；连续5 deg坡面沿+world X上升，出生点位于坡上，没有中央平平台。
- 粗糙面在0.4 m控制格点独立均匀采样[-0.05,0.05] m，再线性插值至0.1 m网格；
  不是5 cm台阶或楼梯，实际min/max及完整网格保留。
- 每环境一块20 x 8 m地形，相对出生点x在[-5,15]、y在[-4,4] m；
  环境间留有间隔，两策略使用相同网格。记录每步边界，若越界即不接受为有效同区域评测。
- 地形静/动摩擦0.4、恢复系数0.8；机器人各shape摩擦0.4、恢复系数0。
  所有实际shape参数读回保存，两策略逐项一致。
- 地面高度按实际三角面重心坐标采样，不能用双线性采样替代三角碰撞面。

保存配置里旧的num_rows/cols等训练地图字段不参与本轮建图；实际地图的唯一来源
是冻结的scenarios网格和显式create_sim代码，mesh_sha256逐批核验两方法完全相同。
同地形两方法初态完全配对；跨地形仅按出生点当地高程调整z，保持相同初始离地高度。

## 净空与原碰撞模型

原资产`replace_cylinder_with_capsule=True`，轮部实际为胶囊碰撞体，不是图片随意画圆。
GPU单体落地校准：横轴放置静止中心高约0.129000 m，竖轴约0.154000 m，
差约0.0249996 m，与半段长0.025 m一致；校准中的共同约2 mm接触偏移
不用于重新定义轮半径。该短校准只辨认几何段长，不替代正式实验的接触参数。
保留校准URDF、源码与结果。

取实际胶囊在世界竖直方向的最低点，并求其到正下方同一三角面的竖向距离。
轮半径0.127 m、胶囊段长0.05 m、原碰撞原点偏移和当前轮姿态均纳入计算。
水平轴退化情形取段中点。保留有符号距离，不把负值裁成0。
它是明确的局部竖向净空，不是全轮体对粗糙面的全局最小分离距离，也不是已验证台阶高度。
接触由实际轮Fz>1 N定义；无接触期间的净空加深着色，接触期间淡线保留。

## 指标与失败

主表从0.02--6.00 s全部记录时刻到首次原机器人终止前统计，失败后不重置/续算新回合。
补充输出1--6 s结果以分离初始化影响。俯仰/横滚均是机体相对世界坐标，
同时保留去均值SD和均值，避免把坡面随动倾角本身当作纯不稳定。

指标为前向速度对0.4 m/s的RMSE、pitch/roll RMS、左/右接触占比、双支撑占比、
左右单支撑与双无接触占比、有效时长及完整6 s无原终止的比例。
左右接触占比各自包含双支撑，所以二者不必相加等于1；四个互斥接触状态和为1。
另保存两策略共同有效窗口的差值与沿指定前进方向的真实速度，避免拿下坡运动作上坡证据。
失败率分母始终90/策略/地形，不用跟踪容差定义失败，不剔除失败轨迹，不补跑替代。

每种策略只有一个训练历程。三评测seed/90环境只表示评测覆盖，不用于伪造训练总体置信带。
