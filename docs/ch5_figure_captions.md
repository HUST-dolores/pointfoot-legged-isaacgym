> **本文档为初稿。** 数值取自当前单基线 seed(Model/Estimate/RL=seed1, Source=seed42),宽负载基底 2–30kg 重训。

- "model-based" 指那条解析(准静态)负载估计,及消费它的两方案(Model/Estimate),**≠** 变体名 "Model-guided"。

## A 组 — 负载估计精度(桥接第四章方法 → 第五章宽负载)

### A1 Load-mass estimation accuracy
- **工况**:平地行走 vx=0.5,负载 2–30kg(每 env 一个固定值),取末段(t>5s)估计均值。
- **对比**:4 方案 encoder 估计 vs 真值散点 + 各自线性拟合 + y=x 理想线。
- **分析**:Model/Estimate 斜率≈0.98、RMSE **1.12/1.20kg**(紧贴 y=x);Source 斜率 1.00 但 RMSE **3.01**(无偏、但尾部噪声大);RL-only 斜率 0.92、RMSE **3.63**(欠估+偏)。→ 带 model-based 估计的两方案在整个 2–30kg 仍高精度,方法可从第四章窄基底平移到宽负载。

### A1b Mass-estimation error vs load
- **工况**:同 A1,逐 env 末段 |估计−真值| 按负载分箱平均。
- **对比**:4 方案的"误差–负载"曲线。
- **分析**:Model/Estimate 误差全程平直、不随负载发散(~1kg 量级);Source/RL 在大负载端更大。→ 估计不在大负载饱和(对照旧窄 [2,4]kg 基底约 4kg 饱和),证明宽负载下方法仍成立。

### A1c Load CoM-offset estimation accuracy
- **工况**:同 A1,估计质心偏置 CoM x / y vs 真值,两子图,轴均 [−0.2, 0.2] m。
- **对比**:4 方案的 CoM 散点 + y=x,图注标 RMSE。
- **分析**:CoM 普遍估得准——RMSE(x/y):Model 0.022/0.015,Estimate 0.017/0.010,Source 0.012/0.009(最佳),RL 0.019/0.023。→ 不止质量,连质心偏置都准,为 C4 偏心实验铺垫。

### A2 Estimation in time domain(固定 26kg)
- **工况**:平地行走 vx=0.5,**固定 26kg**,同步循环加/卸载(载 6s → 卸 10s)。每方案一张图,3 子图 mass/CoMx/CoMy 绝对值 vs 时间;真值(黑)/ model-based 解析(灰虚)/ encoder(变体色)。mass 子图四图统一 [−10, 60]。
- **对比**:同一方案内三条线(真值 vs 解析 vs encoder);四张图横比四方案的跟踪能力。
- **分析**:看 encoder 线是否快速贴住黑色真值线、加载阶跃后多快收敛、卸载后是否归零。**好效果 = 贴黑线、阶跃响应快、无持续偏差**。

### A2b Estimation RMSE vs time(四方案)
- **工况**:同 A2 的循环负载数据,对所有带载 env 算 RMSE(t)=√(meanᵢ(est−true)²),3 子图,阴影=env 间 25–75% |误差|;mass 子图 y 锁 0–30。
- **对比**:4 方案 encoder 的 RMSE(t) 叠加。
- **分析**:**低且收敛快者更好**。加载后 Model/Estimate 的 mass RMSE 迅速降到 ~1–2kg,Source/RL 更高更慢。是 A2 的定量正文版("是否收敛、稳态误差多大")。

## C 组 — 控制 / 抗倾覆(核心论点:负载辨识提升抗倾覆)

### C0 Load CoM height vs load mass(物理基础,与策略无关)
- **工况**:居中负载、100 env/方案、读 `true_com_delta_z`(每-env 末段中位)。横轴负载质量,纵轴负载质心竖直偏置 [cm]。
- **对比**:四方案合并(策略无关),~400 点 + 一条总拟合曲线;点按变体着色以验证重合。
- **分析**:z 随质量**饱和上升(非直线、非立方根)**——`Δz[cm]=23.4·m/(9.62+m),R²=0.9984`。**物理推导**(代码 base_task.py:1460 的质量加权质心 `com_eff=(m0·c0+m·r)/(m0+m)`):Δz = h·m/(m₀+m),其中 **m₀=9.62kg ≈ trunk 质量(URDF base_Link 9.585kg)**、**h=23.4cm = 负载挂点高出 trunk 质心**(= r−c₀ = 7.0−(−16.4)cm;c₀=URDF trunk 惯性原点 z −16.4cm,r≈有效挂点 7cm)。半饱和点 m=m₀≈9.6kg(负载与机身等重时质心升一半),轻载斜率 h/m₀≈2.4cm/kg。→ "越重质心越高但边际递减"的根因是**质量加权(非几何立方根)**,是"越重越易倾覆"(C1–C5)的**物理基础**;四方案点重合,确认与策略无关。

### C1 Terminal upright-rate vs slope × load(热图)
- **工况**:行走上坡 vx=0.5,坡度 {8,12,16,20,22,24,26,28}°,负载 2–30kg 分箱。每方案一子图。
- **对比**:4 方案在 坡度×负载 网格上的末态直立率。
- **分析**:暖=稳。Model/Estimate 在 22–24° 仍大面积暖(尤其中高负载);Source/RL 在 24° 已普遍变冷。直观展示抗倾覆边界差异,且负载越大边界越敏感。

### C1b Slope survival vs slope(对负载平均)【正文主图】
- **工况**:同 C1,对所有负载 env 平均,4 条线 + 0.5 参考线。
- **对比**:4 方案的存活–坡度曲线。
- **分析**:悬崖式跌落。关键 **24°:Model 0.71、Estimate 0.71 vs Source 0.04、RL 0.04**(model-based 组高约 18×);20°:Model 0.99 / Estimate 0.97 vs RL 0.82 / Source 0.45;28° 全崩(≤0.08)。→ model-based 组把抗倾覆边界整体抬高约 4°。

### C2 Anti-tipping boundary β*(load)
- **工况**:同 C1,β* = 末态直立率跌破 0.5 的临界坡度(线性插值),vs 负载,y 轴 [16,28]°。
- **对比**:4 方案的 β*–负载。
- **分析**:把 C1 压成单一"抗倾覆边界"标量。均值 **Model 25.0° = Estimate 25.0° > RL 21.1° > Source 19.5°**。model-based 组领先 RL ~4°、领先 Source ~5.5°。(注:单 seed;Source 用的 seed42 偏弱,多 seed 补充中。)

### C3 Downhill e-stop distance vs load
- **工况**:下坡 10°,巡航 vx=1.5 → 急停归零,负载 2–30kg。停车距离 = 指令归零起机体 x 最大前移,vs 负载(散点+分箱均值)。
- **对比**:4 方案的停车距离–负载。
- **分析**:**短=好**(更快稳住)。均值 Estimate 0.86m、Model 0.97m < RL 1.43m、Source 1.45m。→ 知道负载→正确制动→冲得近。

### C3b Downhill e-stop trajectory(固定 26kg)【补充】
- **工况**:同 C3 但**固定 26kg**(四方案严格同负载),画单 env 指令归零后的 x 位移 vs 时间。
- **对比**:4 方案在同一重载下"怎么停"。
- **分析**:重载放大差距——RL-only 冲出 **3.38m**(刹不住),Estimate 仅 0.37m,Model/Source ~0.85m。直观演示 C3 的机理。

### C4 Forward lean under load(偏心)
- **工况**:静止、平地、负载 2–30kg。两子图:左 x=0(居中竖直)、右 x=0.20m(前偏,偏心力矩∝m·offset)。末段前倾 pitch(负=前倾) vs 负载。
- **对比**:4 方案的前倾–负载,居中 vs 偏心。
- **分析**:居中(x=0)@28kg:Estimate −2.4°、Model −2.9° 比 RL −5.7°、Source −6.4° 站得更直(model-based 组省力压住竖直重载)。偏心(x=0.2)更杂(各 −3~−7°),偏心力矩下控制更难、差异被噪声掩盖。→ 主要支持"居中重载下 model-based 组前倾更小"。

### C5 Lateral push (40 N) disturbance rejection vs load
- **工况**:静止、平地、负载 2–30kg(质量随机,`--keep_load` 保真载)、**负载位置居中**(`--load_offset 0,0`,去掉位置随机)、**100 env/方案**、+Y 持续 40N。末段峰值 |roll| vs 负载。
- **对比**:4 方案的抗横推–负载。
- **分析(初稿,单 seed)**:居中数据全负载平均峰值 |roll|:**Model 11.5° / Estimate 7.3° / Source 9.0° / RL 10.9°**,聚在 7–11°、**无清晰高下**(Model 最高、Estimate 最低,二者同属 model-based 组 → 组内 4° 差是噪声;RL 也并非最差)。→ **C5 没有体现负载辨识对横向抗扰的系统性增益**;去掉位置随机后数值整体抬高(随机偏置原本平均掉一部分)且排名重排,更说明此项无稳健结论。机理上横推不产生"随负载增大的倾覆力矩"(竖直载不加 roll 力矩),故本图**定位为边界/对照**(辨识对纯横推无系统帮助),不作正面证据。

### C5b Lateral push roll response(固定 26kg)【补充】
- **工况**:同 C5 固定 26kg,画单 env roll vs 时间。
- **对比**:4 方案同重载下的 roll 动态(怎么晃、怎么恢复)。
- **分析**:看恢复速度与残余幅度,配合 C5 的统计作定性轨迹。

## D 组 — 机理 / 可解释性

### D1 Actor-IG attribution by input group
- **工况**:各方案 actor 对输入分组的积分梯度(IG)归因(target=all, coarse),聚成 5 类:Load latent / Explicit model-based obs / Raw torques / Prev actions / Other。
- **对比**:4 方案各输入类的归因占比。
- **分析**:Model/Estimate 读显式 model-based obs(7.2 / 14.4%),Source/RL 无此 obs(0)。但 Load latent 占比都很低(1.5–2.9%),Prev actions 主导(59–75%)。→ **关键警告:IG≠因果必要性(局部梯度),低 IG ≠ 不重要**,见 C6。

### D1b Actor-IG detail heatmap【附录】
- **工况**:同 D1 但全输入组(coarse)× 4 方案热图,颜色=归因%。
- **对比**:细分到每个具体输入组。
- **分析**:附录级细节,展示完整归因分布(哪些 obs 维度被读)。

### C6 Runtime latent ablation(运行时因果)【机理主图】
- **工况**:测试时(**同一 Model 权重,不重训**)消融 policy-facing 负载 latent。三子图:
  - **A** none vs shuffle(env 间互换=错配) vs zero_all(置零) @22/24°。
  - **B** latent 缩放 ×{0.5,0.8,1.0,1.5,2.0} 剂量–反应 @22/24°。
  - **C** 喂固定负载 latent {5,15,25}kg × 真实负载箱 热图 @24°(CoM 置零)。
- **对比**:同一策略,只改运行时喂入的负载估计。
- **分析**:
  - **A**:24° none **0.71 → shuffle 0.34 → zero 0.00**(22°:0.91→0.79→0.00)。置零塌台、错配明显退化 → **运行时确实因果依赖这个 latent**(尽管 D1 里它 IG 低)。
  - **B**:中等缩放(0.8–1.5)稳健,大错配(0.5/2.0)退化 → 用的是"大致正确的量级"而非精确 kg。
  - **C**:喂入 ≈ 真实负载时存活更高(对角更暖)→ latent 与真实负载的对应关系驱动抗倾覆。
  - → 这是"**为什么负载辨识能提升抗倾覆**"的金标准因果证据(对照 D1:IG 高的显式 obs 其实冗余,真正起作用的是 encoder latent)。

## 帧条示意图 — 定性可视化(单 env 代表轨迹,2D 侧视,配合统计图)
共用画法:机器人侧视姿态由真实记录的关节角(hip/knee)+ base pitch/height/x 经矢状面前向运动学画出(thigh≈shank≈0.30m,轮径 0.127m);**淡色=初态、实色=末态**,只取各自最有信息量的两个极值帧 + 一个方向箭头。**均为单 env(env0)、单 seed 的定性示意,数值与对应统计实验同源同量级。**

### C9 起步过程对比(23kg / 20° 坡爬升)【可视化 C1/C2】
- **工况**:同一 23kg 负载、**20° 坡**——选 20° 因其落在 Model β\*≈24° 裕度内、RL β\*≈19° 之外,正是图5.6"边界差≈4°"的可视化(24° 时 Model 自身也临界,单轨迹也会翻,见 §9 笔记)。
- **对比**:Model 用**位置极值**(起点→最远)+ 绿色**前进箭头**;RL 用**俯仰极值**(最仰→最俯)+ 红色**旋转弧**。
- **分析**:Model 在坡上**持续上行 +9.8 m、机体始终直立**(收敛到稳定爬升步态);RL **俯仰 0→−89° 前倾倾覆**、原地栽倒。把图5.6/C1 的统计"边界差"落成可见的"稳爬 vs 倾覆"。

### C10 急停刹车帧条(26kg / 下坡 10° 急停)【可视化 C3 / 图5.7】
- **工况**:搭载 26kg 下坡 10°,巡航 vx=1.5 → 指令归零急停。以"**急停点(cmd→0)**"为基准红旗,取刹车点(淡)→停止点(实)两帧。
- **对比**:Model vs RL,红色**平移箭头**长度 = 刹车点后机体前移(超调)。
- **分析**:**超调 Model 0.85 m vs RL 3.38 m(≈4×)**——Model 短刹停住、RL 冲过头。把图5.7"0.9 vs 3.5 m"刹车差落成可见画面。

### C11 偏心定点漂移帧条(平地 / 13kg 前置偏心)【可视化 §9.5】
- **工况**:平地、13kg **前置偏心**负载(load_offset_x=0.15,负载框画在机体前方 + 重量箭头示意偏心)、静止指令 cmd=0。以"**起点**"为基准红旗,取起点(淡)→最大位移点(实)两帧。13kg 为甜区(中等偏心力矩:Model 守得住、RL 守不住;重载 26kg 时 Model 也被推漂,见 §9.5)。
- **对比**:Model vs RL,红色**平移箭头**长度 = 净漂移。
- **分析**:**漂移 Model −0.80 m(守在起点附近)vs RL +4.73 m(被偏心力矩 ∝m·g·d 推着前漂)**——印证 §9.4 双线性机理(偏心激活∝负载扰动→无估计守不住)。**注**:平地偏心仅"RL vs 其余"干净、QS 估计内部分不开(§9.5),故本图定位为机理示意,而非四方梯度正面图。
